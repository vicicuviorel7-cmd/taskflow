## Descriere

TaskFlow este o aplicație web pentru gestionarea
proiectelor, echipelor, sarcinilor și pontajului.

## Funcționalități planificate

- Autentificare și înregistrare
- Gestionarea proiectelor
- Gestionarea echipelor
- Panou Kanban drag-and-drop
- Pontajul orelor
- Algoritmul drumului critic CPM
- Compararea efortului planificat și realizat
- Rapoarte și statistici
- API REST

## Tehnologii planificate

- PHP 8.4+
- MySQL / MariaDB
- HTML, CSS, JavaScript
- Composer
- Git și GitHub
- PHPUnit
- MVC și Repository
