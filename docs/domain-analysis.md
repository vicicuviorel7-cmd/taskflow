## 4. Noțiuni fundamentale

- Proiect: ansamblu de activități orientate spre
  atingerea unui obiectiv.
- Sarcină: activitate individuală dintr-un proiect.
- Echipă: grup de persoane care colaborează.
- Pontaj: evidența timpului efectiv de lucru.
- Dependență: relație între două sarcini.
- Kanban: reprezentarea vizuală a fluxului de lucru.
- CPM: metoda drumului critic.

## 5. Componenta interdisciplinară

Voi implementa algoritmul Critical Path Method
(CPM) pentru determinarea duratei minime a
proiectului și identificarea sarcinilor critice.

Voi utiliza următorii indicatori:

ES = momentul minim de începere.
EF = momentul minim de finalizare.
LS = momentul maxim de începere.
LF = momentul maxim de finalizare.
D = durata sarcinii.
TF = rezerva totală de timp.

Formule:

EF = ES + D
LS = LF - D
TF = LS - ES

Sarcinile cu rezerva totală egală cu zero
sunt considerate critice.

## 6. Analiza efortului

Voi compara efortul planificat cu efortul realizat.

Abatere = Efort realizat - Efort planificat

Procent utilizat =
(Efort realizat / Efort planificat) * 100

Procentul se calculează numai dacă efortul
planificat este mai mare decât zero.
